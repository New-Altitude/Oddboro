- [runtime] **Decision (2026-11-11): the existing desktop shell and job clock supply bounded local runtime evidence.** Setup and the read-only `office_runtime` tool read the same records. Native startup, restart, login and power-request events are distinct from clock gaps; a gap never proves its cause. The packaged app does not prescribe the development login service. A failed clock read schedules another check without adding a second scheduler. Code in the desktop `runtime.rs`, ledger `runtime.ts` and office `jobs.ts`; review and release checks in `docs/runtime-evidence.md`.
