- [staff] **Decision (2026-11-09): a `hand_off` can carry named files, copied into the sender's part of the thread.** Work often depends on a file the sender holds, such as notes or a draft, and the colleague had only the brief to go on. The sender names as many files as an email may carry (`MAIL_FILES_MAX`, `HandOff.files`) that it can read, in its own folder (the owner's chat attachments among them, in `attachments/`) or the folder of work it is on, each by its path there or its full path, and the office copies each into the sender's part of the thread's folder, where everyone on the thread reads it. `readableFile` decides what a sender can read, and an unreadable file, an instruction file, a hidden file, one of the office's own files at the top of its folder (`OFFICE_FILE_NAMES`), or a file in its folder reached through a link, such as an `attachments/` swapped for one, refuses the hand-off with an error that says what to do, so nothing is handed off half-furnished. A file the office cannot open refuses it the same way. Every refusal names a file as the sender named it, so the sender can pass that name back. A file already in the work is never changed: a carried file with the same bytes is not copied again, and one with other bytes refuses the hand-off, naming both. Every file is checked before any is copied, so a refused hand-off leaves the work's folder as it was. The colleague's brief lists each file at its full path in the work's folder, and names one no longer there as gone, which is how a hand-off a v0.0.9 office stored, with paths in the giver's own folder, reads (the 2026-11-10 ruling). This reopens the 2026-11-02 ruling that files cross by copy only narrowly: a copy, never a link, and only what the sender can already read. The owner ruled this on 2026-11-09. Files a hand-off copies in fall under the 2026-11-03 rule that what an Odd sees through a thread is no wider than its access. `tell_lead` copies the owner's attachments by the same checks and copy, one file at a time, so one that cannot land is named in the lead's note and the rest still go.
