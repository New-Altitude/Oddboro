- [office] **Decision (2026-11-08): a task can carry a response the owner edits, and the Odd gets the saved words when the owner finishes the task.** One editor shows on the Desk and on the task's card in chat, and it is the only place the chat takes a typed answer to a task: a plain question opens it empty, and Save and finish saves the words and finishes the task in one click. Choices are still a tap. Finishing on the chat card marks it as from chat, so the Odd's reply comes back under the card; finishing on the Desk adds nothing to the chat. An Odd passes `response` to `give_owner_a_task` instead of a file to fill in: starting text only when the task is to edit it and its title says so, such as a draft list, and none for a question. The editor names the Odd's starting text as its draft, with Clear. Attached files are then only to read. A task with a shared list can start its response from that file. Drafts belong to the task, so moving between tasks keeps them. Each save names the version it opened, so a stale save never overwrites newer words, and a retry after a failed finish uses the version just saved. The saved words are the owner's answer in the Ledger and on the Desk's recent answers. Code in `packages/ledger/src/office.ts` (`saveTaskResponse`, `finishTask`), `apps/office/src/lib/ui/TaskResponse.svelte` and `task-response.svelte.ts`.
