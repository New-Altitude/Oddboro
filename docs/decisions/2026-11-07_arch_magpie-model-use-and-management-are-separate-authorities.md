- [arch] **Decision (2026-11-07): using a published Magpie model does not require authority to manage that installation.** On this integration branch, a positively identified local gateway can expose its exact model and group-alias catalog without a management key; provider, account, group-edit and inspection operations remain behind explicit management authorization. This avoids forcing an existing gateway user to locate a desktop access link just to select a model. Saved connections remain authoritative, failed switches preserve the working setup, and only an explicit successful switch changes the source and session boundary. Public protocol metadata does not prove process ownership; an existing gateway is never stopped by Oddboro. The private bundled runtime retains authenticated instance checks and child ownership, while HTTPS servers retain explicit management and inference credentials. Reasons, code paths and verification are in `docs/magpie-architecture.md` and `docs/magpie.md`.
