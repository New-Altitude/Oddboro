- [staff] **Decision (2026-11-12): a hire proposal for a real person whom New Altitude offers the signed-in account as a persona opens that persona's install, never a local look-alike.** The hire window shows the persona with Add, which starts the same install as Setup's Add, so the persona still joins only on the owner's click; Build an ordinary Odd instead opens the builder without the person's name, role or appearance. A proposal matches a persona by its slug, or else by the persona's whole display name as the proposal's name or role ("<Full Name> Persona"), never by a first name, and two matches are none. A proposal that says it means a persona (a slug, or the word persona) and has no match asks for the New Altitude sign-in while the owner is signed out, offers Try again while New Altitude does not answer, and says so when New Altitude does not offer the person; an ordinary Odd built from it never starts with the person's name, role or appearance. A proposal with only a whole name builds an Odd as before when there is no match. A local Odd drawn to look like a real person would speak for them without their say. Code in `apps/office/src/lib/persona.ts` (`proposedPersona`) and `apps/office/src/lib/ui/HireDrawer.svelte`.
