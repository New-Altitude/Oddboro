- [office] **Decision (2026-11-13): the owner can attach one project folder to a goal, and Goals can group goals by that folder to show their work, progress, waiting decisions, shared files and native sessions together.** The folder is an optional field on the goal, not another project record. Attaching it grants no file access and starts no work. Goals without folders keep their area view. The owner can change or remove the link without moving files or sessions. Native sessions stay behind Advanced mode. The view uses the existing Goals pane, work status, file viewer and Projects window. Code in `apps/office/src/lib/server/goal-projects.ts` and `apps/office/src/lib/ui/GoalProject.svelte`.
