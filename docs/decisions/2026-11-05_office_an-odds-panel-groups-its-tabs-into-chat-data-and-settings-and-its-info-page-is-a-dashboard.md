- [office] **Decision (2026-11-05): an Odd's panel groups its tabs into three, Chat, Data (Lessons, Storage) and Settings, each an icon and a word, and its name opens an info page laid out as a dashboard that holds In progress and Jobs; supersedes the same day's Chat, Knowledge and Settings ruling.** Five tabs in a row left no room, and a flip card hid most of what an owner wants to see about an Odd. The info page is one scrolling page, most useful first: who it is, what it is doing and what its runs go through; In progress; Jobs, each opened to edit in place, with "+ Add a job" and when it runs next; the job description; stats; its look, with Redraw look and Send to a place. In progress lists every run of the Odd going now, a pick-up after a task or a colleague, work handed over and parked work waking among them, and each follow-up still waiting to start, which says it starts once the Odd's current run on that work ends, so work the owner's answer started never looks like nothing (amended 2026-11-11). While an Odd has work in progress, a count in a turning ring sits beside its name and opens the page at In progress; the ring turns only while there is work, and not under reduced motion. Chat is the chat alone: no placeholder tabs for what is not built. Storage lists everything in the Odd's own folder, then under Shared work its part of each thread it is on, one folder per piece of work by its title, newest first, all searchable and opened in the office's viewer; it never lists the office's own chat log and session file, an instruction file, a hidden entry or a link, and stops at 5,000 entries across both. It reads the folders when the tab opens; nothing watches them. Code in `apps/office/src/lib/ui/StaffCard.svelte`, `OddInfo.svelte`, `StorageTab.svelte` and `apps/office/src/lib/server/storage.ts`. This supersedes this ruling's 2026-11-05 text that had Storage list only the Odd's own folder.
