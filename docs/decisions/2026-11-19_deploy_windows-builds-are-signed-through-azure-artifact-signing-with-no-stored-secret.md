- [deploy] **Decision (2026-11-19): the Windows app, installer and uninstaller are signed with New Altitude's certificate in Azure Artifact Signing, by the release workflow alone, with no signing secret stored anywhere: each file signs in to Azure with a fresh GitHub OIDC token from the `release` environment, and a Windows release built on GitHub that is not signed stops.** An unsigned installer made Windows SmartScreen warn every owner before it ran, and a stored certificate or client secret is one more thing to leak or expire. Detail in `apps/desktop/CLAUDE.md` ("Releases come from GitHub only") and `apps/desktop/scripts/sign-windows.ts`.
