- [staff] **Decision (2026-11-02): a staffer's run reads only its own folder, the owner's data folder and, on Claude Code, its Claude Code project folder; everything else on the computer is denied by path.** A staffer that reads untrusted mail or web pages could otherwise be steered into reading `~/.ssh`, other staffers' notes or the office's own sign-ins. Path-scoped `Read` allows replace the bare `Read`, `Glob` and `Grep`, and an explicit deny list backs them up against broad allows in the owner's own Claude Code settings. The rules live in `readable` and `unreadable` in `apps/office/src/lib/server/staff.ts`; `apps/office/CLAUDE.md` lists them. A staffer on Grok or Codex reads the same data folder, and a kernel sandbox profile holds its files too (the 2026-11-04 rulings).
