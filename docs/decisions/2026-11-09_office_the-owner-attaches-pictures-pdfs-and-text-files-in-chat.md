- [office] **Decision (2026-11-09): the owner attaches pictures, PDFs and text files to a chat message, and each one is kept in the Odd's own `attachments/` folder, where the run reads it with its own file tools.** Pasting or dropping a file puts its tag at the caret (`[Image #1]` for a pasted picture, else the file's name), Attach files in the plus menu beside the box adds files to the tray alone, and a column over the plus button and Send, three files tall before it scrolls, previews everything that goes; deleting a tag drops its file. Every run already reads its Odd's folder, so no new path opens, and the prompt names each file's full path by its tag. Codex, whose picture tool is off, gets the pictures with the message (`--image`). Up to 10 files of 10 MB each, each uploaded alone before the message, so the Mac app raises the server's body limit to 11 MB. Code in `apps/office/src/lib/server/chat-files.ts`, `src/lib/attachments.ts` and `ChatPanel.svelte`.
