- [staff] **Decision (2026-11-04): an Odd can also run on Gemini, with file tools only and one policy file per run as its one write wall, and "Runs on" hides Gemini until a live run holds that wall.** Gemini CLI has no kernel sandbox to lean on, so the office gives a Gemini Odd no shell and lets Gemini's own policy engine decide every call. A run is `gemini -o stream-json` from the office's Gemini home, `<ODDBORO_HOME>/gemini` (`GEMINI_CLI_HOME`), never the owner's `~/.gemini`. Its reads are held to its folder, the owner's data folder and its thread folders (`--include-directories`). Its policy, passed as `--policy` and so Gemini's user tier, denies every tool it does not name, allows the read tools and the MCP tools access allows, allows a write only by full path under its folder and its part of a thread, and refuses an instruction file there in any case, the file the owner edited in any case, and any path with a `.` or `..` part, `//`, a backslash or a character past ASCII (APFS folds the Kelvin sign to `k`). Measured with Gemini CLI 0.66.0's own policy loader and engine (`gemini-policy.test.ts`, which runs when `gemini` is on PATH and says it skipped when not): the loader reads the policy with no rule dropped, and the engine, with Gemini's default rules beside it and an allow-all standing in for settings, decides 36 calls as meant, forged paths in a file's content and the case and spelling dodges included. A Gemini run signs in only with an API key the owner gives on the office's page, kept in the keychain like the Claude key, and with none it says so and starts nothing: the Google login was refused when tried ("This client is no longer supported for Gemini Code Assist for individuals"). `AGENT_PLATFORMS` gives Gemini no system, so neither "Runs on" nor the sign-in card offers it; one live run on a Mac that holds the wall adds `darwin`. Untested: every live run, so the walls against a real model, the API key sign-in and MCP over `httpUrl`; thinking tokens, which Gemini's source leaves out of `output_tokens`; a comma in a path, since Gemini splits `--policy` and `--include-directories` on commas; and Gemini expands "@path" in its input. The model comes from `OFFICE_GEMINI_MODEL`. Code in `apps/office/src/lib/server/gemini.ts`; `apps/office/CLAUDE.md` item 9 lists the rules.
