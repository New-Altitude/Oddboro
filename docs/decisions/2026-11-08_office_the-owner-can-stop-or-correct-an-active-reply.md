- [office] **Decision (2026-11-08): the owner can stop or correct an active chat reply.** Stop names the attempt on the saved turn, so an old window cannot stop a later run. A correction keeps its words and files before it stops the reply and waits for the run to end. The chat records which reply stopped; completed actions stand. Closing a window lets the run finish. A message about a job or goal in progress names the work and goes to its lead, leaving the background slots alone. Code in `apps/office/src/lib/server/staff.ts` and `apps/office/src/lib/ui/ChatPanel.svelte`.
