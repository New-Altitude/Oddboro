- [office] **Decision (2026-11-11): the owner can stop an active chat reply, or add to it with Send now.** Stop names the attempt on the saved turn, so an old window cannot stop a later run. The chat records which reply stopped; completed actions stand. Later runs hear a stopped reply as stopped by the owner, never as failed, and do not pick it back up unless asked. Ordinary Send queues a message while a reply runs. On a Claude Code Odd, Send now (or Ctrl+Enter, on every system) adds the queued words to the running reply, which answers them in the same turn: a chat run reads stream-json and keeps stdin open until its result. The chat keeps the words as an owner line of that turn. A reply that already gave its result takes nothing, and the words go as the next message. Codex, Grok and Gemini read their message once, so they only queue. A message with files, about a desk item, or about a job or goal waits its turn; one about work in progress goes to its lead, leaving the background slots alone. Closing a window lets the run finish. Correct this reply is gone; Send now covers it. This supersedes the 2026-11-08 ruling.
