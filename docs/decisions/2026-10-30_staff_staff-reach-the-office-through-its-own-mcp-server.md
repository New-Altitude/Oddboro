- [staff] **Decision (2026-10-30): staff reach the office through its own MCP server, started per run with the staffer's id. Every staffer can raise asks, see how the owner decided them, and see its own access. The owner grants the rest per staffer from the Settings tab: search the ledger, give the owner tasks, find tools, ask for tools, and the office report. The server offers only what that staffer holds.** One server holds the rules for every staffer, and a staffer can only act as itself. A tool goes with a grant, never with a name, so every Office Manager gets the report the same way. New hires start with everything but the office report. Code in `packages/ledger/src/mcp.ts`, the `mcp-*.ts` files it loads, and `packages/ledger/src/tools.ts`.
