- [arch] **Decision (2026-11-04): Oddboro ships as a Tauri shell in Rust that runs the office server on a bundled Node: a signed, notarized Mac app for Apple Silicon, an AppImage for Linux on x86_64 and arm64, and a per-user installer for Windows on x64 and arm64, and on all three an update installs in place once the owner says yes.** A container cannot reach the owner's keychain, Claude Code sign-in or notifications, and we support only the newest version. An AppImage is the one Linux format Tauri's updater can replace in place, and on Windows the updater runs the new installer, which needs no administrator. The detail lives in `apps/desktop/CLAUDE.md`; where the code and the owner's office live is `packages/ledger/src/home.ts`. Supersedes the 2026-11-03 ruling that it ships for the Mac and Linux only, and the 2026-11-04 wording that every update is required.
