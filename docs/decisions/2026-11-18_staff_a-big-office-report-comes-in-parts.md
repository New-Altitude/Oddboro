- [staff] **Decision (2026-11-18): an office report too big for one tool result comes in parts.** `office_report` returns the whole report while it fits 40,000 characters of compact JSON. Past that it returns each Odd in brief, then one Odd in full when called with `odd`, its runs in pages with `page`. A run that got a result too big for it lost it to a file the Odd could not read, so a 24 or 72 hour report never loaded (#201). Paging keeps the Odd's folders as they are, where reading that file would have widened them. Code in `packages/ledger/src/office-report.ts`.
