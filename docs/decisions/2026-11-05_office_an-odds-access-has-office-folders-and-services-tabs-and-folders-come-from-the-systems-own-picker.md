- [office] **Decision (2026-11-05): an Odd's Settings tab (Access before it held the model) has four tabs, Model, Office, Folders and Services; Model holds the tool as setup's square tiles, the permission level and Thinking; Office, Folders and Services each have a search box over their list; and a folder is chosen in the system's own folder picker, with the typed path kept as the way in where none opens.** One long page mixed what the Odd does in the office with what it reaches outside, and typing a path was the hardest step for an owner. Office lists Run commands and Browse the web, with their locks and why lines (`commandsHow`, `webLine`), above the office's own tools, and an Always on group follows with every tool the owner cannot switch that some run of that Odd is offered (`isOffered`), one row each with its name and what it does, built from `OFFICE_TOOLS` (`toolGroups`), which the owner ruled on 2026-11-09 in place of a hand-written line; Folders lists each folder with Can read and Can write side by side, and a new one starts at Can read; Services holds the outside tools. Each tab shows an icon and its word, and the icon alone when the bar is narrower than 22rem (a container query, no measuring). The office runs on the owner's computer, so `/api/folders/pick` opens the picker there: AppleScript's `choose folder` on a Mac, the Forms folder dialog in PowerShell (`-STA`) on Windows, zenity or else kdialog on Linux, the prompt always an argument or environment variable, never script text. A cancel picks nothing; with no dialog tool or no screen (`DISPLAY`, `WAYLAND_DISPLAY`) the page says why and keeps the typed path. One picker opens at a time and closes after five minutes. The picked path goes through the same staff PATCH and `checkFolder` as a typed one, so the picker widens nothing. Only the owner gives a folder, but an Odd asks for one with `ask_for_folder`, never with steps for its Settings tab (added 2026-11-07, after an Odd gave the owner such steps): the ask names the folder and Can read or Can write, is refused at once by the same checks, and its Desk card's Give access gives that folder, or a narrower one the owner picks there with the same picker, and approves the ask in one transaction, so the run the answer starts reaches it. The Mac app's Tauri dialog plugin is not used: the server's picker serves the browser and the app alike. This supersedes the 2026-11-04 ruling where it said folders are typed with no picker. Code in `apps/office/src/lib/server/folder-picker.ts`, `AccessTab.svelte` and `FoldersList.svelte`.
