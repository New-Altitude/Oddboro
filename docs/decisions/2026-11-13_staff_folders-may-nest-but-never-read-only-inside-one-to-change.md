- [staff] **Decision (2026-11-13): an Odd's folders may sit one inside another, but never a folder only to read inside one to change.** A run reads every folder it has and changes those to change, as it already reads a work's folder and changes only its own part, and every tool's walls take a read list and a write list, so a folder to change inside one to read, or two at one level, holds as the card says. A folder to read inside one to change could not stay read only, since every tool lets a run change all of the outer one, so it is refused either way round, by a new folder or a level change (`FOLDER_REFUSED.readInsideChange`). Allowing two at one level lets the Settings tab, which adds each folder at read before the owner switches it, take a folder to change inside one to read in either order. A folder dropped for holding keys still counts against a folder that would hold it (`FOLDER_REFUSED.nested`). `nestRefused` in `packages/ledger/src/office-folders.ts`, for `setFolder` and `folderAskRefused`. Supersedes the 2026-11-04 ruling there.
