# Log a recording day from a calendar

Give the Odd read access to the calendar that holds the recording sessions. Open its Jobs, choose **Add a job**, and name it **Log recording days**. Set the schedule and turn on the report to your desk. To cover a day the office misses, choose the option that fills missed runs.

Paste the instructions below. Replace the calendar name, time zone and words that identify your sessions. A calendar entry establishes that a session was scheduled. The people making the recording can confirm whether it happened.

```text
Read the Production calendar for the date this job covers, in America/Los_Angeles.
For a catch-up, check each missed date separately. Read every page of results.
Use the current occurrence of each event. Count sessions titled Recording or
Recording session. Skip canceled occurrences and events about preparing or
reviewing a recording. Use the current start time of a rescheduled occurrence.

Put the date and each scheduled session's title and local start time on my desk.
Include its event link or ID so I can check it. If the whole date was checked and
there were no sessions, say so. If you cannot read the calendar or finish the
search, say what you could not check and leave that date unverified.
```

For a schedule change, ask for the specific event and new time in a separate message. Grant read and write access to that calendar. Keep the Odd at **Draft** and set the calendar change to ask first. Review the event, old time and new time on your desk. After approval, have the Odd read the same event back. If a previous attempt may already have worked, check its current time before asking for the change again.
